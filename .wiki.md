# Project Summary
This project is a browser-based “Personal Mind Map” editor that lets users create and reorganize a node tree with comments and hyperlinks, then export the result in multiple formats (JSON, Markdown, and image/document formats). It also records visitor activity and triggers weekly report runs for analytics and feedback.

# Project Module Description
- Backend (app/backend, FastAPI)
  - Provides domain-organized APIs for health/auth/user settings, feedback submission, visitor logging, report runs, and storage/AI hub integration.
  - Uses ORM models with migration support via Alembic.
- Frontend (app/frontend, React + TypeScript)
  - Mind map SVG canvas: interactive node selection, dragging/reparenting, zoom/pan, and text editing with RTL/LTR aware layout.
  - Node formatting toolbar: alignment, direction, numbered/bulleted lists, bold, and font size controls applied to selected nodes.
  - Export & save: Save menu to download as JSON/Markdown/JPG/PNG/SVG/PDF, with website stamping rules per format.
  - State handling: restores/saves editor state in localStorage, tracks unsaved changes, and shows export/save options.

# File Description Inventory
- app/frontend/index.html
  - Sets initial HTML title/language metadata.
- app/frontend/src/components/MindMapCanvas.tsx
  - Renders and edits the SVG mind map (zoom/pan, node interactions), applies node text formatting, and stamps the website at the bottom for image/document exports.
- app/frontend/src/components/Toolbar.tsx
  - Provides fixed top toolbar with language, undo/redo, save format submenu, node color/comment/link controls, and selected-node text formatting menu (alignment/direction/list/bold/font size).
- app/frontend/src/i18n/translations.ts
  - Translation strings and RTL/LTR detection utilities.
- app/frontend/src/i18n/useTranslation.ts
  - i18n provider/hook utilities used by UI components.
- app/frontend/src/pages/Index.tsx
  - Restores and persists mind map state in localStorage, warns on unsaved work, sets document title and direction, wires keyboard shortcuts, and handles save/export actions.
- app/frontend/src/hooks/useMindMap.ts
  - Tree operations: add child/sibling-before, delete, reparent via drag, text/color/format updates, and undo/redo history; ensures new nodes inherit parent color.
- app/frontend/src/types/mindmap.ts
  - Types for nodes and formatting patches (align, direction, listStyle, bold, fontSize), plus default creation/color resolution helpers.
- app/frontend/src/lib/mindmapExport.ts
  - Build/export helpers for JSON/Markdown (website in header) and PDF (website in footer), plus download utilities and export constants.
- app/frontend/src/components/*, app/frontend/src/lib/*, app/frontend/src/pages/* (existing)
  - Remaining UI and API wrapper glue not detailed in this inventory.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic, relational database persistence
- Frontend: React, TypeScript, Vite, Tailwind CSS, lucide-react
- Exports: SVG generation, rasterization to PNG/JPG via canvas, PDF generation via jsPDF, JSON/Markdown file builders
- i18n: runtime translations with RTL/LTR support
