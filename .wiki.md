# Project Summary
This project is a browser-based Personal Mind Map editor that lets users create and organize mind maps, then share them via token-based read-only links (optionally password protected with expiration handling). It also includes an authenticated admin manager dashboard for operational control and reporting, plus supporting public content flows like About/Support and feedback.

# Project Module Description
- Backend (FastAPI)
  - Admin APIs (`/api/v1/admin/*`)
    - Admin management and operational/reporting endpoints.
    - Storage proxy endpoints used by the frontend for upload/download URL resolution.
    - Share/admin-controlled behavior integrations.
  - Shared maps
    - Token-based mapping of share payload references (`object_key`).
    - Optional password protection (hashed) and expiration enforcement.
    - Cleanup support for expired shares.
  - Shared content access (read-only)
    - Token/password validation and retrieval of shared payload content.
    - Returns expired/notfound states appropriately.
- Frontend (React + TypeScript)
  - Mind map editor (public)
    - Interactive node editor with mobile-friendly touch/drag behavior.
    - Share flow creates share tokens and navigates/copies share links.
  - Shared view (read-only)
    - `/shared/:token` renders mind maps as non-editable; prompts for password when required.
  - Standalone integration mode
    - Uses an in-house API client (no external SDK) to call backend endpoints directly (configurable via `VITE_API_BASE_URL`).
    - Auth callback page acts as a redirect placeholder for standalone mode.
  - Keyboard shortcuts behavior (desktop)
    - Enter adds a sibling after the current node.
    - Shift+Enter adds a child to the current node.
    - Tab removes focus/uses normal browser navigation behavior for the UI element.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Frontend: React, TypeScript, Vite, Tailwind CSS
- Storage: object storage accessed via backend using `object_key` (frontend uses admin storage proxy endpoints)
- Admin: authenticated `/manager` dashboard (legacy)
- i18n: runtime translations supporting RTL/LTR rendering
- Deploy support: sitemap + optional blog prerender via Vite plugins

# Usage
## Frontend
- Install: `pnpm i` (within `app/frontend`)
- Build: `pnpm run build`
- Lint: `pnpm run lint`

## Backend
- Follow `app/backend/README.md` for build/run instructions
- Quick check: `python -m py_compile ...`
