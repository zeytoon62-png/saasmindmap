# Project Summary
This project is a browser-based “Personal Mind Map” editor that lets users create and reorganize a node tree with comments and hyperlinks, then export the result in multiple formats (JSON, Markdown, and image/document formats). It also drives a site experience with visitor feedback submission and admin-configured “About Us” and “Support Us” sidebar content, including a password-protected admin manager at `/manager` for operational configuration and reporting.

# Project Module Description
- Backend (FastAPI)
  - Admin management & reporting
    - `/api/v1/admin/*` endpoints manage admin authentication, admin users, site settings, crypto wallets, feedback listing, and reporting (with optional feedback-type filtering).
    - Reporting includes enhanced visibility into email delivery activity via a dedicated email logs endpoint.
  - Email system
    - New admin-configurable SMTP settings are required for outgoing email functionality.
    - Feedback dispatch logic:
      - Normal feedback: collected/aggregated over a configured interval, then sent as a single batch email to both configured normal recipients.
      - Urgent feedback: sent immediately in real time to both configured urgent recipients.
    - All outgoing emails are persisted to an email logs store for dashboard review.
  - Wallet QR management
    - Wallet management supports QR image uploads (stored in object storage) so the public “Support Us” menu can display the correct QR image per wallet.

- Frontend (React + TypeScript)
  - Public editor UI integration
    - Sidebar and modal interactions (About Us, Support Us, Feedback) use admin-provided settings.
  - Admin manager UI (`/manager`)
    - Dashboard tab includes reports plus email sending logs.
    - Settings tab includes multilingual About Us editing, full SMTP configuration, email recipient configuration for normal/urgent feedback, and batch scheduling controls.
    - Wallets tab supports QR image upload and preview from object storage.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic, async DB persistence
- Frontend: React, TypeScript, Vite, Tailwind CSS
- i18n: runtime translations with RTL/LTR rendering
- Email: SMTP via admin-configured settings
- Storage: object storage integration for QR image upload/download
