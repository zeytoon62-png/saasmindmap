# Project Summary
This project is a browser-based “Personal Mind Map” editor that lets users create and reorganize a node tree with comments and hyperlinks, then export the result as JSON or an image; it also supports backend collection of visitor activity and feedback for weekly reporting.

# Project Module Description
- Backend (app/backend, FastAPI)
  - Loads configuration, manages database sessions, authentication/token utilities, shared enums, and masking/crypto helpers.
  - Exposes API routes grouped by domain (health/auth/user/settings, feedbacks/visitor_logs, report runs/reports, storage/ai hub).
  - Contains domain services for auth, feedback submission, visitor logging, report runs, weekly reports, and storage.
  - Persists data via ORM models and schema migrations (Alembic).
  - Entry points: FastAPI app composition plus a serverless handler.
- Frontend (app/frontend, React + TypeScript)
  - Mind map canvas: SVG-based interactive editor with zoom/pan, node editing/drag/reparent, comment + hyperlink editing, and PNG export.
  - UI: fixed toolbar with language switching, color picker redesign, unsaved-changes indicator, and dialogs for feedback and node-level metadata.
  - Page orchestration: restores/saves editor state in localStorage, warns on navigation/refresh with unsaved changes, and updates document title + RTL/LTR direction.
  - i18n: runtime translations and RTL/LTR support.

# Directory Tree
- app/
  - backend/
    - alembic/ : Alembic migrations
    - core/ : config/auth/db/enums/crypto utilities
    - data_models/ : seed/reference JSON datasets
    - dependencies/ : FastAPI dependency providers
    - models/ : ORM models for auth/reporting/feedback/visitor logs
    - routers/ : API routers by domain
    - schemas/ : request/response schemas
    - services/ : domain services (reports, feedback, visitor logs, storage, etc.)
    - skills_docs/ : AI/custom API/object storage/web SDK docs
    - utils/ : logging utilities
    - main.py, lambda_handler.py, requirements*.txt, README.md, alembic.ini
    - start_app_v2.sh
  - frontend/
    - public/ : static assets
    - src/
      - components/ : MindMapCanvas, Toolbar, and UI components
      - hooks/ : mind map state/operations (useMindMap.ts)
      - i18n/ : translations and translation hook utilities
      - pages/ : Index page (editor orchestration)
      - lib/ : API client wrapper
    - index.html, build/dependency manifests, MGX config

# File Description Inventory
- app/frontend/index.html
  - Sets initial HTML title/language metadata.
- app/frontend/src/components/MindMapCanvas.tsx
  - Renders and edits the mind map (zoom/pan, node interactions) and supports PNG export.
- app/frontend/src/components/Toolbar.tsx
  - Fixed toolbar and sidebar/drawer UI, language switching, color picker UX, and dialogs entry points.
- app/frontend/src/i18n/translations.ts
  - Translation strings plus RTL/LTR detection helpers.
- app/frontend/src/i18n/useTranslation.ts
  - i18n provider/hook utilities.
- app/frontend/src/pages/Index.tsx
  - Loads/restores mind-map state, persists changes to localStorage, warns on unsaved changes, sets title and `dir`.
- app/backend/*
  - Backend modules are organized into core, routers, services, models, and alembic migrations as described above.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic, relational DB persistence
- Frontend: React + TypeScript, Vite, Tailwind CSS, lucide-react
- Export/UI: SVG canvas rendering to PNG/JSON
- i18n: RTL/LTR support and runtime language switching
